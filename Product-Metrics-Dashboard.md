# Product Metrics Dashboard

## Objective
Track key product metrics to measure product performance, user engagement, and business growth.

## North Star Metric
**Weekly Active Users (WAU)**

## Key Performance Indicators (KPIs)

| Metric | Target | Status |
|---------|--------|--------|
| Monthly Active Users (MAU) | 10,000 | 🟡 In Progress |
| Weekly Active Users (WAU) | 5,000 | 🟡 In Progress |
| Daily Active Users (DAU) | 1,500 | 🟡 In Progress |
| User Retention Rate | 80% | 🟡 In Progress |
| Customer Satisfaction (CSAT) | ≥ 4.5/5 | 🟡 In Progress |
| Net Promoter Score (NPS) | ≥ 50 | 🟡 In Progress |
| Task Completion Rate | 90% | 🟡 In Progress |
| Average Session Duration | 10+ Minutes | 🟡 In Progress |
| Churn Rate | < 5% | 🟡 In Progress |
| System Uptime | 99.9% | 🟢 Healthy |

## Dashboard Sections

### User Growth
- New Users
- Active Users
- Returning Users

### Engagement
- Daily Active Users
- Weekly Active Users
- Average Session Duration
- Tasks Created
- Tasks Completed

### Customer Satisfaction
- CSAT Score
- Net Promoter Score (NPS)
- User Feedback Rating

### Business Metrics
- Conversion Rate
- Customer Retention
- Churn Rate
- Revenue (if applicable)

### Product Performance
- System Uptime
- Average Response Time
- Bug Reports
- Feature Adoption Rate

## Reporting Frequency
- Daily: Active users, uptime, bug reports
- Weekly: Engagement and retention
- Monthly: Business performance and customer satisfaction

## Deliverable
A centralized dashboard that tracks product health, user engagement, customer satisfaction, and business performance to support data-driven product decisions.
