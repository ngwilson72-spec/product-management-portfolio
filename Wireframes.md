# Wireframes

## Objective
Design the basic layout and user flow for the TaskFlow application before development.

## Screens

### 1. Login Screen
- Email and Password fields
- Login button
- Sign Up link
- Forgot Password option

### 2. Dashboard
- Navigation menu
- Project overview
- Task summary
- Upcoming deadlines
- Notifications

### 3. Task Management
- Create new task
- Edit task
- Delete task
- Assign team members
- Set priority and due date

### 4. Project Board
- Kanban board (To Do, In Progress, Review, Done)
- Drag-and-drop task management

### 5. Analytics Dashboard
- Completed tasks
- Pending tasks
- Team productivity
- Project progress charts

### 6. User Profile
- Profile information
- Account settings
- Notification preferences
- Security settings

## User Flow

1. Login
2. View Dashboard
3. Create Project
4. Add Tasks
5. Assign Team Members
6. Track Progress
7. Complete Tasks
8. View Analytics

## Deliverables
- Low-fidelity wireframes
- User flow diagram
- Navigation structure
- Screen layout documentation

## Acceptance Criteria
- Covers all core screens
- Easy and intuitive navigation
- Supports responsive design
- Ready for UI design and prototyping
